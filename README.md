# The Loft by NM — Luxury Salon & Spa Sanctuary

A modern, responsive web application for **The Loft by NM**, an exclusive beauty and spa sanctuary located in a restored colonial house in Colombo, Sri Lanka.

## Features

- **Luxury Brand Experience**: Tailored typography, refined animations, and high-performance WebP imagery.
- **Service & Ritual Showcase**: Detailed menus for hair design, couture nails, bridal styling, and restorative facial therapies.
- **Private Ladies' Suite**: Dedicated experience preview and booking flow.
- **Appointment Scheduling**: Integrated booking system with Supabase backend and Google Calendar integration.
- **Direct WhatsApp Concierge**: Instant booking confirmation and consultation.
- **Admin Management Portal**: Custom dashboard to manage bookings, inquiries, waitlists, reviews, and careers.
- **PWA & Mobile Ready**: Offline capability, installable PWA badge, and mobile-first responsive layout.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS + Custom Design System
- **Database / Auth**: Supabase
- **Icons**: Lucide React
- **Animations**: Motion (Framer Motion)

## Local Development

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure environment variables**:
   Create a `.env` file based on `.env.template`:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
